PF-04 M  Batch Monte Carlo scoring - only if the whole scoring kernel can be
         compiled; otherwise skip. Survival: improve the algorithm first.
Rules: Numba stays an OPTIONAL dependency with a pure-Python fallback; cache=True;
compile in a kernel only numeric arrays (no dataclasses, dicts, closures).
Not worth it: multi-peak model (already vectorised: 0.2 ms for 5 peaks x 2000
points; Jacobian 7 ms for 21 parameters - a fit of 50 iterations is well under
a second) and model-specific Jacobians (they need the whole chain compiled:
model -> residual -> perturbation -> Jacobian; large effort, small gain).
Never target: Qt panels, Matplotlib rendering and style editing, pandas,
statsmodels, scikit-learn, SciPy wrappers, string/SQL/catalogue logic.
